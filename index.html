02 / Tentang Saya Latar Belakang & Pengalaman

Saya merupakan lulusan Teknik Informatika yang memiliki minat pada pengembangan teknologi digital, khususnya web development dan UI/UX design. Saya memiliki pengalaman magang di dua perusahaan dengan berkontribusi dalam pengembangan Sistem Manajemen Internal berbasis website yang mengintegrasikan pengelolaan informasi dan data dari berbagai divisi ke dalam satu platform terpusat untuk mendukung efisiensi administrasi dan koordinasi internal di PT. Nusareka Prima Engineering. Selain itu, saya terlibat dalam perancangan UI/UX aplikasi QRIS Merchant untuk mendukung pengembangan layanan digital perbankan, serta pembuatan berbagai media komunikasi dan promosi digital, seperti flyer, poster, dan materi publikasi untuk sosialisasi produk, layanan, serta program perusahaan, termasuk kegiatan kerja sama dan program wakaf di PT. Bank Riau Kepri Syariah (Perseroda).

Melalui proyek akhir, saya turut mengembangkan Virtual Reality (VR) Istana Siak dengan berfokus pada 3D modeling bangunan dan arsitektur interior untuk menghadirkan pengalaman eksplorasi virtual yang imersif.

Selama perkuliahan, saya juga aktif terlibat dalam kegiatan Pengabdian kepada Masyarakat (PKM) bersama civitas akademika, di antaranya pelatihan bisnis digital bertema “Strategi Pemasaran Produk UMKM di Era Digital” dan workshop “Administrasi Web Server dengan CWP”. Selain itu, saya berkontribusi dalam kegiatan hilirisasi riset Game Edukasi Berhitung “Brilian” untuk Anak Tunagrahita Ringan.

Berbagai pengalaman tersebut telah membekali saya dengan kemampuan teknis, komunikasi, kolaborasi, pemecahan masalah, serta adaptasi terhadap berbagai kebutuhan dan lingkungan kerja. Saya memiliki rasa ingin tahu yang tinggi, inisiatif, dan semangat untuk terus belajar serta mengembangkan kemampuan diri.

Pelatihan bisnis digital untuk membantu pelaku usaha mikro dalam meningkatkan visibilitas produk mereka melalui platform pemasaran daring, tata kelola promosi media sosial, dan pembuatan konten visual yang menarik guna memperluas jangkauan pasar.

KEGIATAN 02 2024 • Peningkatan Kompetensi Guru SMK

Workshop: “Administrasi Web Server dengan CWP”

Pelatihan teknis yang ditujukan bagi para guru SMK untuk meningkatkan kompetensi kejuruan dalam mengelola server hosting dan konfigurasi server name (nameserver/DNS) menggunakan Control Web Panel (CWP), sebagai penunjang materi ajar dan pengelolaan infrastruktur web di lingkungan sekolah.

Peran: Asisten Instruktur & Fasilitator Workshop
Mendampingi para guru SMK selama pelaksanaan workshop administrasi web server menggunakan CWP guna memastikan seluruh tahapan hands-on dapat diikuti dan dipraktikkan dengan baik.
Membantu para guru dalam memahami konsep serta implementasi pengelolaan server hosting dan konfigurasi server name, serta membantu mengatasi kendala teknis (troubleshooting) saat sesi praktik berlangsung.
Mendukung instruktur utama dalam memandu jalannya sesi laboratorium komputer secara interaktif guna menunjang kesiapan pengajaran materi terkait di sekolah.

Hilirisasi Riset Game Edukasi Berhitung “Brilian” untuk Anak Tunagrahita Ringan
