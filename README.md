# Website Portofolio Pribadi — Pure HTML, CSS, JS (Warm Editorial)

Website portofolio pribadi modern dan profesional dengan estetika **Warm Editorial**, dibangun murni menggunakan **HTML5, CSS3, dan Vanilla JavaScript** tanpa ketergantungan framework (*no React, no Vue, no Vite, no node_modules*).

## 📂 Struktur Section (Sesuai Urutan Wajib)

1. **01 / Profil (Hero):** Perkenalan singkat profesional, foto profil potret berkarakter, status ketersediaan proyek, dan 3 tombol navigasi (`Lihat Portofolio`, `Tentang Saya`, `Hubungi Saya`).
2. **02 / Tentang Saya:** Narasi komprehensif perjalanan di bidang teknologi serta katalog 7 bidang keahlian (*Web, UI/UX, Android, Pemodelan 3D, Virtual Reality, GIS, Deep Learning*).
3. **03 / Portofolio:** Tepat 5 proyek spesifik dengan variasi layout visual yang dinamis dan modal pratinjau studi kasus interaktif:
   - *VR Istana Siak* (Pemodelan 3D / Virtual Reality)
   - *SIJAGAT: Aplikasi Deteksi Api dan Asap* (Pengembangan Android / Deep Learning)
   - *Sistem Manajemen Internal PT. Nusareka Prima Engineering* (Full-Stack Web Development)
   - *Dzapin Merchant (QRIS Merchant) PT. Bank Riau Kepri Syariah* (Desain UI/UX & Rekomendasi Desain)
   - *FUTSAL-GO* (GIS / Pengembangan Web Pekanbaru)
4. **04 / Pengabdian kepada Masyarakat:** Tiga slot dokumentasi terstruktur untuk inisiatif sosial, edukasi literasi digital, dan pendampingan UMKM.
5. **05 / Sertifikat dan Pelatihan:** Galeri sertifikat fleksibel dengan filter kategori serta modal perbesar (*Certificate Lightbox*) untuk inspeksi kredensial.
6. **06 / Kontak:** Bagian terakhir berisi ajakan kolaborasi, salin email 1-klik (`kontak.raihanpratama@gmail.com`), profil LinkedIn, GitHub, formulir pesan interaktif, dan footer hak cipta.

## 🚀 Cara Menjalankan

Website ini **dapat dibuka langsung** tanpa perlu instalasi apa pun:

1. **Buka Langsung:**
   Cukup klik ganda (double-click) file `index.html` di File Explorer, dan website akan langsung terbuka di browser Anda (Chrome, Edge, Firefox, Safari).

2. **Atau Gunakan Server Lokal Ringan (Opsional):**
   ```bash
   # Menggunakan Python (jika terpasang)
   python -m http.server 8000
   
   # Atau VS Code Live Server / PHP
   php -S localhost:8000
   ```
   Lalu buka `http://localhost:8000` di browser.
