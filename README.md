# Personal Portfolio

Website portofolio pribadi yang menampilkan profil, pengalaman, keterampilan, dan beberapa proyek yang pernah saya kerjakan di bidang teknologi digital.

## Teknologi

Website ini dibangun menggunakan:
- HTML5
- CSS3
- Vanilla JavaScript

## Fitur

- Profil dan informasi pribadi
- Tentang saya dan bidang keahlian
- Galeri proyek dan detail portfolio
- Dokumentasi kegiatan dan pengabdian masyarakat
- Galeri sertifikat dan pelatihan
- Informasi kontak dan tautan profesional

## Struktur Project

```
ProfileWebsite/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```

## Menjalankan Project

Website dapat dijalankan secara langsung dengan membuka file `index.html` melalui browser tanpa memerlukan instalasi framework atau dependensi tambahan.
